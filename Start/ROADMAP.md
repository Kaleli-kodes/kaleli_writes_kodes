# Development roadmap

1. **Foundation:** Next.js/TypeScript monorepo, PostgreSQL migrations, account system, multi-tenant authorization, audit log and CI.
2. **Business core:** API-backed products, sales, expenses, customers, suppliers, credit, documents and private receipt storage.
3. **Intelligence:** reports, deterministic metrics, audited AI tool layer, confirmed natural-language transaction drafts.
4. **Resilience:** IndexedDB sync queue, server idempotency, notification preferences, PWA install/update UX.
5. **Readiness:** accessibility and security testing, monitoring, backups/restores, country configuration review and deployment.
