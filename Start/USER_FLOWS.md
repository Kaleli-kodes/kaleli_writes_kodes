# User flows

```text
First visit → business setup → inventory → add product → Home
Home → record sale → review/confirm → sale saved → stock reduced → dashboard recalculated
Sales → credit sale + customer → balance increases → Customers → record payment → balance decreases
Expenses → record expense → dashboard/report recalculated
Assistant → question → authorized calculated records → answer or “not enough data”
```

The production onboarding adds account creation, email verification, country and business profile before this flow. Natural-language input always pauses at a confirmation screen prior to creating a transaction.
